# Code de conduite / Code of conduct

ADB Tools Pro est un projet ouvert à tous : techniciens, intégrateurs, développeurs, débutants comme confirmés.
ADB Tools Pro is open to everyone: technicians, integrators, developers, beginners and experts alike.

## Ce que nous attendons / What we expect

- Rester courtois, patient et bienveillant, surtout envers les nouveaux venus. / Be courteous, patient and kind, especially with newcomers.
- Critiquer les idées et le code, jamais les personnes. / Criticise ideas and code, never people.
- Accepter qu'un avis différent soit possible, et savoir reconnaître une erreur. / Accept differing opinions and own your mistakes.
- Respecter la confidentialité : ne jamais publier les données d'un client, d'un employeur ou d'une autre personne. / Respect confidentiality: never post data belonging to a customer, an employer or another person.

## Ce qui n'est pas accepté / What is not accepted

- Insultes, moqueries, harcèlement, propos discriminatoires de quelque nature que ce soit. / Insults, mockery, harassment or discriminatory remarks of any kind.
- Contenu sexuel, violent ou haineux. / Sexual, violent or hateful content.
- Publication d'informations privées sans accord (doxing). / Publishing private information without consent (doxing).
- Spam et publicité. / Spam and advertising.

## Application / Enforcement

Le mainteneur peut modifier ou supprimer un message, verrouiller une discussion ou bloquer un compte qui ne respecte pas ces règles.
Pour signaler un comportement, utilisez le bouton **Report content** de GitHub sur le message concerné, ou le [signalement privé](https://github.com/Kanard-Compagny/ADBToolsPro/security/advisories/new) si le message expose des données confidentielles.

The maintainer may edit or remove messages, lock discussions or block accounts that break these rules.
To report behaviour, use GitHub's **Report content** button on the message, or the private report link above if it exposes confidential data.
