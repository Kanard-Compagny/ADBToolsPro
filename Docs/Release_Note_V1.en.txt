1. OVERVIEW
================================================================================
ADB Tools Pro is a desktop tool that makes diagnosing professional Android
devices (Zebra, Honeywell, Samsung...) simpler, faster and safer. It wraps the
power of ADB in a modern, responsive graphical interface, so technicians no
longer have to type command lines by hand.

Every tab has been tested on real hardware; known limitations are listed at
the end of this document (section 9).

2a. WHAT'S NEW IN VERSION 1.6.0 (November 2026)

MASTER (new menu page)
  - Restore devices after a wipe, any brand that supports ADB: a reference
    device is captured, then the Master is reinjected onto one or several
    devices in parallel.
  - Capture (nothing is changed on the reference device): apps (split APKs
    included) and their permissions, disabled apps, Android settings,
    language and time zone, Wi-Fi networks, default launcher, device owner
    (kiosk / MDM). Settings specific to each device (identifiers, counters,
    hardware state) are left out.
  - Master created by hand, without a reference device ("Create" button).
  - Content shown in tabs; everything can be checked and changed before
    sending:
    . Apps, with their origin: MDM agent (device owner), pushed by the MDM
      (managed Google Play), installed by hand, shipped with the device.
      Only MDM apps and apps installed by hand are checked by default.
    . Settings as a form per theme (screen, sound, language and time,
      network, security): "Don't change" or an imposed value, in plain
      words. Technical settings explained, sorted by category, unchecked
      by default.
    . Wi-Fi: security type (WPA2, WPA2/WPA3, WPA3, open, 802.1X, WEP),
      password, hidden network.
    . Manual steps, guided by templates: Google account, enterprise Wi-Fi,
      certificate, MDM enrollment, date, language. The chosen screen opens
      on the device at the end of the restore.
    . Files (e.g. DataWedge configuration) and ADB commands.
    Anything left to complete (Wi-Fi password, missing APK) is shown in
    orange.
  - Each checked device is analyzed before sending: apps missing, older,
    identical or newer; different model or Android version. Choice per
    app: install, update, keep the device's version, downgrade.
  - Report per device: every item applied, already in place, skipped or
    refused with the reason in plain words; every changed setting with its
    old and new value. Excel export.
  - Small "ADB Tools Helper" app (no icon, stays on the device): saves Wi-Fi
    networks ("cmd wifi connect-network" is reserved for rooted devices
    since Android 11) and changes the system language. Android removes an
    app's networks when it is uninstalled: it is only replaced when too
    old, and the report says so.
  - As a last resort, a Wi-Fi QR code to scan from the device (Settings >
    Wi-Fi > QR icon), also available network by network.
  - .adbmaster file (zip archive) to share within the team. Wi-Fi passwords
    are stored in clear text: keep it somewhere safe.
  - Limits: app internal data cannot be copied without root (that is the
    MDM's job); the device owner can only be set on a device without
    accounts, right after a wipe.

OTHER IMPROVEMENTS
  - Guided tour completed (Master).
  - QR codes generated with QRCoder (MIT, see THIRD_PARTY_NOTICES.txt).

2b. WHAT'S NEW IN VERSION 1.5.0 (November 2026)
================================================================================
OS UPDATE (new menu page)
  - One or several USB-connected devices updated at the same time, each
    with its own progress. Any brand that supports ADB.
  - Three methods:
    . Over the cable (ADB sideload): automatic switch to "update from ADB"
      mode; if a model does not allow it, its row asks to choose "Apply
      update from ADB" and sending starts by itself.
    . Copy to device storage, then Recovery ("Apply update from SD card /
      internal storage"): for models that refuse sideload. Checked copy,
      deleted after the update.
    . Fastboot (factory image): unlocked bootloaders only, with a detailed
      warning. Nothing is flashed if the bootloader is locked, or if the
      model or bootloader version does not match.
  - Checks before sending: model targeted by the package (including the
    Zebra platform and DeviceManifest.xml), device already up to date,
    incremental update, battery below 30 %.
  - Going back to an earlier version: refused by Android with a normal
    package (reported before sending). With the manufacturer's "downgrade"
    package, the device goes through "Downgrade from ADB"; it is wiped, as
    the confirmation reminds.
  - Single package, or library: a folder of packages (yours or the team's)
    where ADB Tools picks the newest package meant for each model. A mixed
    fleet is updated in one go.
  - On return: restart and check of the new version, then optional app
    installs (APKs picked one by one or a whole folder) and ADB commands.
  - Simultaneous transfers can be limited from 5 devices (shared USB hub).
  - A transfer already started is never interrupted; ADB Tools refuses to
    close while a device is being updated.
  - Excel summary (.xlsx): versions before / after, method, package,
    colour-coded result, details, times.

OTHER IMPROVEMENTS
  - Windows taskbar icon: green progress while a task runs (live logs,
    Wi-Fi, OS update…), flashes at the end of an OS update if ADB Tools is
    in the background.
  - The OS update menu button pulses during an update, like other tasks.
  - Advanced tools reorganised (OS update has its own page).
  - Orange buttons dimmed when unavailable.
  - Guided tour completed: Logs, Comparator, File analysis, OS update.

2c. WHAT'S NEW IN VERSION 1.4.0 (November 2026)
================================================================================
FILE ANALYSIS (new menu page)
  - Opens a log set received from the field: Zebra RxLogger archive,
    bugreport, unzipped folder or logcat. All dated logs are merged in
    chronological order with no line limit; ANR, tombstones, snapshots and the
    kernel log remain viewable (with search).
  - Search as you type (text or regex), level, tag, PID and log filters;
    "Go to the incident" (e.g. 9:07 ± 5 min); "Show context".
  - Timeline: lines and errors, then one lane per topic (restarts, crashes /
    ANR, Wi-Fi down, memory, battery / heat, scanner), "you are here" marker,
    incidents and bookmarks. Resizable panels.
  - Findings for the area being viewed (they follow scrolling) or for the
    whole log set, with their trend: one-off, steady, rising, falling.
  - Before the incident: never-seen messages, frequency spikes and notable
    events in the minutes before.
  - Business app life: starts, crashes, ANR, stops for lack of memory or by
    the system.
  - Restarts and sessions, with their cause read from the device (OTA update,
    requested shutdown, kernel panic, watchdog, long press, battery...).
  - Team known issues: a message saved with its diagnosis and solution is
    recognised automatically in later log sets (file shared in the team
    distribution folder).
  - Bookmarks with notes; comparison of two log sets (with / without a patch).
  - Customer Word report in the format of the service and Wi-Fi reports
    (template customisable in Settings ▸ Word reports), detailed technical
    report as PDF or HTML, lines exported as .txt / .csv.

FIELD RECORDER (File analysis ▸ Field recorder)
  - The unplugged device records for several hours the full Android log, its
    state (battery, temperature, memory, storage, Wi-Fi), Wi-Fi drops and the
    incidents the user reports with one tap ("Report an incident", also in the
    notification), with the system state at that moment.
  - Back at the PC, "Retrieve the recording" opens it in File analysis, on the
    first incident.
  - Android 13 and later: accept "Allow access to all device logs" when the
    recording starts.

OTHER IMPROVEMENTS
  - Log analysis: Zebra scanner faults detected (sensor no longer returning
    images, trigger presses without a read), routine Zebra and Play Store
    messages ignored.
  - The title bar keeps its size whatever the interface zoom.
  - Third-party tools: automatic retry when GitHub returns a transient error.
  - "Open a file" on the Logs page opens File analysis.
  - 64-bit program for large log sets.

2d. WHAT'S NEW IN VERSION 1.3.0 (November 2026)
================================================================================
AUTOMATIC LOG ANALYSIS (Logs page)
  - "Analyse displayed logs": the whole live capture is reviewed, even lines
    hidden by filters.
  - "Quick device analysis": reads the current device log (logcat -d) and
    analyses it in one click, without starting the capture.
  - "Open a file": saved logcat (.txt, .log), bugreport (.zip) or Zebra
    RxLogger archive (.zip, latest logs merged) received from a customer or a
    colleague.
  - What is detected: app crashes (Java and native), frozen apps (ANR),
    restarted services, memory pressure, full storage, battery (level,
    temperature, health), overheating, restarts, Wi-Fi (disconnections and
    their reason, rejected password, DHCP, roaming), DNS, unreachable servers,
    certificates, and barcode scanners of all brands (DataWedge, Honeywell,
    Datalogic, Newland, Urovo...), including a sensor that no longer returns
    images and trigger presses that produce no read.
  - Problems are grouped and sorted from most to least serious, each with a
    piece of advice; a click shows the line in the table. Report to copy or
    export as .txt for a ticket.

DEVICE COMPARATOR (new menu page)
  - Two connected devices, a device and a reference (.adbref: approved model
    device), or a device and one of its previous states.
  - Compares identity and system (Android version, security patch, build,
    baseband...), apps and their versions, disabled apps, Android settings and
    properties.
  - Values specific to each device (serial number, addresses, counters) are
    ignored: only real differences stand out.
  - Each snapshot is stored in the device history (when it changed): ideal to
    see what an update or an intervention changed.
  - Export of the differences table as .csv (Excel).

DEVICE TESTS (SAV Diagnostics ▸ Lab)
  - A diagnostic app is installed for the duration of the tests, then
    uninstalled. It detects the hardware present: tests impossible on this
    model are greyed out.
  - On-demand tests, all optional: back and front cameras (photo
    retrieved), flash, speaker, earpiece, microphone (measured level,
    recording you can play back), vibrator, sensors, NFC, GPS, Bluetooth,
    physical keypad, storage speed.
  - Measured result when possible, confirmed by the technician otherwise;
    always editable, with a comment.
  - Only the tests done go into the report ("Tests on the device" table): a
    test not done or not applicable is left out.
  - Android 8 to 16, standard Android features.

BARCODE SCANNER TEST (SAV Diagnostics ▸ Lab)
  - A small test app is installed on the device for the duration of the
    test, then uninstalled automatically.
  - Live reads: data (invisible characters shown), length, symbology (sent
    by Zebra and Honeywell, estimated otherwise).
  - Trigger detected: delay until the read, missed reads, success rate;
    pace in reads per minute.
  - List of expected codes (test sheet): differences reported.
  - Result added to "Scanner optics" (diagnostic and Word report).

CABLE-FREE WI-FI SURVEY (Wi-Fi Analysis ▸ Cable-free survey)
  - The device measures Wi-Fi on its own, unplugged from the PC, while you
    walk around the site: signal, access point, channel, link speed and ping
    every second; access point changes and drops recorded. Works with the
    screen off.
  - Markers added on the device ("Dock 3", "Office"...): signal and loss
    summary by zone.
  - When back: "Retrieve the data" shows the survey in the Wi-Fi Analysis
    (charts, statistics, log); the Word report includes it.

UPDATES, AS IN SCANALYSE
  - The "Update X" badge appears in the title bar, next to the version. A
    click opens the install window with what's new, then "Install and
    restart".

OTHER IMPROVEMENTS
  - Service diagnostics: besides PASS and FAIL, a row can be set to
    "Monitor" or reset to "Not tested".
  - Wi-Fi check-up: correct SSID and access point (BSSID) on Android 11.

6. THE CONNECTION BAR (always visible, on every tab)
================================================================================
- Drop-down list of detected devices, with a state indicator (connected /
  unauthorized / offline) and automatic refresh every 2 seconds.
- "Connect": opens the session with the selected device.
- "Dev Off": remotely revokes USB debugging (with confirmation).
- "Reboot" and "Recovery Mode": normal reboot or reboot to recovery.
- "Wi-Fi Pairing": wireless (TCP/IP) connection to the device, with both
  methods depending on the Android version: classic pairing (Android 5+) and
  native code pairing (Android 11+).

7. FEATURES BY TAB
================================================================================

[📱 Dashboard]
- Device identity at a glance: model, OS version, build, SDK API, serial
  number, uptime, screen resolution/DPI.
- Real-time gauges (battery, RAM, CPU, storage) with automatic colour coding
  (green / orange / red) and a details panel when clicking each gauge.
- Built-in free ADB command console, with a history of previous commands.

[📺 Mirroring]
- Shows the device screen on the PC through scrcpy (very low latency), with
  options: turn off the physical screen, keep awake, mute, show touches.
- "Multi-device mirroring": opens a mirroring window on several connected
  devices in one action.
- Instant screenshot (PNG) and screen video recording, with an automatic
  watermark (company name, model, date).
- Dedicated captures folder, with optional automatic saving.

[📦 Package Manager]
- Full list of installed apps, with filters (user / system / disabled) and
  search by package name.
- Multiple selection for grouped actions: launch, force stop, enable/disable,
  clear cache/data, extract APK, uninstall — each confirmed before running.
- Install by drag and drop of an .apk file or split APKs.
- "Install on several devices": pick an APK once and install it on several
  connected devices, with an individual result per device.
- Real-time activity sniffer (app in the foreground on the device).

[📁 Explorer]
- Built-in browser for the device file tree, with shortcuts (sdcard,
  Download, tmp).
- Push and pull files with multiple selection, progress bar and cancel.
- Create folders, rename and delete remotely.

[⚡ Advanced tools]
- Physical key simulator (Home, Back, Volume...).
- Direct switches: Wi-Fi, Bluetooth, airplane mode, NFC, location,
  auto-rotate, dark mode.
- Settings with values: brightness, density (DPI), screen resolution (with
  reset to factory values), screen timeout, volume per audio stream, ringer
  mode.
- XML extractor of the displayed interface (UI Automator dump), useful to set
  up scanning apps (Velocity, ProGlove...).
- OS update has its own page since version 1.5.0 (see section 2b).

[🔧 Service diagnostics]
- A single sheet, one line per part of the device, grouped by category; the
  label on the right says who tests (PC, device, or either).
- PC automatic check-up: ADB authorization, root, battery, storage,
  temperatures, crashes / ANRs, sensors, Wi-Fi, ping.
- ADB Tools Diag app tests started from the sheet (one test or the whole
  run), results retrieved in one click.
- Live listening from the PC: physical keys (with stuck key detection) and
  touched areas; colour patterns sent to the screen; live barcode scans.
- Kept result and comment editable at any time, history per line; "New
  test" to start again on another device.
- JSON export (RMA) and Word report ready for the customer: summary and
  verdict, table by category, touch grid as an image.

[📡 Wi-Fi analysis]
- Live monitoring of the connection: SSID, BSSID, IP and MAC addresses,
  signal level (RSSI), band and channel, link speed, gateway and DNS.
- Two live charts side by side: latency and signal strength, each with
  min/average/max statistics and live counters.
- Live roaming and Wi-Fi disconnection sniffer through logcat.
- Plain-text network report and Word report (.docx) with both charts and the
  full raw event log.

[📚 ADB library]
- Ready-to-use ADB commands by category, with keyword search.
- "▶ Run" runs the command on the connected device (always confirmed);
  "📋 Copy" copies it for a script. Add and delete custom commands.
- "▶▶ Multi" and "Cmd. Multi.": run a command on several selected devices at
  once, with an individual result per device.
- Export/import of the library as .json, to share commands with the team.

[📝 Logs]
- Real-time logcat capture, without slowing down the interface.
- Filters by severity level, live search (free text or regular expression).
- Targeting of a specific app: automatic detection of the foreground app, or
  manual package name.
- Structured table view or raw data; jump to the next error line.
- Copy the selection, save as .txt, generate the full bugreport (.zip).

================================================================================
8. MULTI-DEVICE EXECUTION
================================================================================
Three actions can run on several connected devices at once, through the same
device picker everywhere in the application: ADB library (saved or free
command), mirroring and APK installation. No device is preselected, a
confirmation lists the exact serial numbers targeted before anything is sent,
and each device gets its own result in the console.

================================================================================
9. TECHNICAL NOTES, SECURITY AND KNOWN LIMITATIONS (V1.2.0)
================================================================================
- Isolated environment: third-party tools (adb.exe, scrcpy.exe, ffmpeg.exe)
  are downloaded into the /Tools subfolder next to the program.
- Asynchronous core: long operations run in the background, the interface
  stays responsive.
- Process safety: automatic clean-up of every external process launched by
  the application when it closes.
- Every destructive or irreversible action is always confirmed before it
  runs, with the exact detail of what will be done.
- The window remembers its size and position between launches.
- Known limitations: Device Info, Package Manager (except installation) and
  Explorer deliberately work on one device at a time. Data you entered
  (command library, categories) stays in the language it was created in.
